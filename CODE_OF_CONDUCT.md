# Código de conduta

Queremos uma comunidade acolhedora para estudantes, professores e desenvolvedores.

- Seja respeitoso, paciente e inclusivo; assuma boa-fé.
- Críticas são sobre o código e as ideias, nunca sobre as pessoas.
- Não toleramos assédio, discriminação, ataques pessoais ou divulgação de dados privados.
- Mantenedores podem remover comentários, issues e PRs que violem estas regras e banir quem reincidir.

Para denunciar, use o aviso privado de segurança do GitHub (aba *Security* do repositório). Inspirado no Contributor Covenant 2.1.
