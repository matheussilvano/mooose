# Página de divulgação (estática)

HTML/CSS/JS puro, sem build. Os números de estrelas/forks e as issues "good first issue" vêm ao vivo da API pública do GitHub.

```bash
python3 -m http.server 8020          # pré-visualizar em http://localhost:8020
npx wrangler deploy                  # publicar no Cloudflare (precisa de wrangler login)
```

`og.html` é só a fonte da imagem de preview social (`assets/og.png`, 1200x630); não é publicado.
